## 1. Слайдер баннеров (ImageSlider)

### Расположение
- **Файл**: `static/js/slider.js`
- **Использование**: Главная страница (`templates/home/index.html`)

### Описание
Класс `ImageSlider` реализует полнофункциональный слайдер изображений с автопрокруткой, навигацией и пагинацией.

### Основные компоненты

#### Конструктор
```javascript
constructor(containerId, options = {})
```
- `containerId` - ID контейнера для слайдера
- `options` - объект с настройками:
  - `images` - массив путей к изображениям
  - `links` - массив ссылок для каждого слайда
  - `captions` - массив подписей для слайдов
  - `loop` - зацикливание (true/false)
  - `navs` - показывать стрелки навигации (true/false)
  - `pags` - показывать пагинацию (true/false)
  - `auto` - автопрокрутка (true/false)
  - `stopMouseHover` - останавливать при наведении мыши (true/false)
  - `delay` - задержка между слайдами в секундах

#### Методы

**`init()`** - Инициализация слайдера:
1. Создает структуру HTML
2. Рендерит слайды
3. Создает навигацию (если включена)
4. Создает пагинацию (если включена)
5. Создает счетчик слайдов
6. Запускает автопрокрутку (если включена)

**`createSliderStructure()`** - Создает базовую структуру:
- Контейнер для слайдов (`slides-container`)
- Контейнер для элементов управления (`slider-controls`)

**`renderSlides()`** - Создает слайды:
- Для каждого изображения создает `<div class="slide">`
- Внутри слайда создает ссылку `<a>` с изображением
- Добавляет подпись, если она указана
- Первый слайд получает класс `active`
- Добавляет обработчики для паузы при наведении мыши

**`createNavigation()`** - Создает кнопки навигации:
- Кнопка "Назад" (◄)
- Кнопка "Вперед" (►)
- Кнопки размещаются поверх слайдов с высоким z-index
- Используется `preventDefault()` и `stopPropagation()` для предотвращения перехода по ссылке

**`createPagination()`** - Создает точки пагинации:
- Для каждого слайда создается кнопка-точка
- Активная точка получает класс `active`
- При клике переходит к соответствующему слайду

**`createCounter()`** - Создает счетчик слайдов:
- Отображает текущий номер и общее количество (например, "1/3")

**`showSlide(index)`** - Показывает слайд по индексу:
- Удаляет класс `active` у всех слайдов
- Добавляет класс `active` текущему слайду
- Обновляет пагинацию
- Обновляет счетчик

**`nextSlide()`** - Переход к следующему слайду:
- Увеличивает `currentIndex`
- Если достигнут конец и включен `loop`, переходит к началу
- Перезапускает автопрокрутку

**`prevSlide()`** - Переход к предыдущему слайду:
- Уменьшает `currentIndex`
- Если достигнуто начало и включен `loop`, переходит к концу
- Перезапускает автопрокрутку

**`goToSlide(index)`** - Переход к конкретному слайду:
- Проверяет валидность индекса
- Устанавливает `currentIndex`
- Перезапускает автопрокрутку

**`startAutoSlide()`** - Запускает автопрокрутку:
- Использует `setInterval` с задержкой `delay * 1000`
- Проверяет флаг `isPaused` перед переходом

**`pauseAutoSlide()`** - Приостанавливает автопрокрутку:
- Устанавливает `isPaused = true`

**`resumeAutoSlide()`** - Возобновляет автопрокрутку:
- Устанавливает `isPaused = false`

**`restartAutoSlide()`** - Перезапускает автопрокрутку:
- Вызывает `startAutoSlide()` для сброса таймера

**`updateDelay(newDelay)`** - Обновляет задержку:
- Изменяет `options.delay`
- Перезапускает автопрокрутку

### Использование
```javascript
const slider = new ImageSlider('banner-slider', {
    images: ['/media/ads/banner1.jpg', ...],
    links: ['/catalog/', ...],
    captions: ['Перейти в каталог', ...],
    delay: 5
});
```

### Особенности
- Администратор может изменять задержку через форму на главной странице
- Значение задержки сохраняется в `localStorage`
- Навигация работает поверх ссылок слайдов благодаря правильному z-index

## 2. Переключатель темы (Theme Switcher)

### Расположение
- **Файл**: `static/js/theme.js`
- **Использование**: Все страницы через `base.html`

### Описание
Реализует переключение между светлой и темной темой с сохранением выбора в `localStorage`.

### Основные компоненты

#### Функция `toggleTheme()`
Переключает тему между светлой и темной:
1. Проверяет наличие класса `dark-theme` на `body`
2. Если тема темная:
   - Удаляет класс `dark-theme` с `body` и `html`
   - Удаляет inline стиль для фона (если есть)
   - Сохраняет 'light' в `localStorage`
   - Меняет иконку на 🌙
3. Если тема светлая:
   - Добавляет класс `dark-theme` к `body` и `html`
   - Сохраняет 'dark' в `localStorage`
   - Меняет иконку на ☀️

#### Обработчик `DOMContentLoaded`
При загрузке страницы:
1. Читает сохраненную тему из `localStorage` (по умолчанию 'light')
2. Применяет класс `dark-theme` к `html` и `body`, если тема темная
3. Устанавливает правильную иконку на кнопке переключения

### Использование
Кнопка переключения находится в `base.html`:
```html
<button id="theme-toggle" onclick="toggleTheme()">🌙</button>
```

### CSS стили
Темная тема применяется через класс `dark-theme`:
- `body.dark-theme` - темный градиент фона
- `.nav-list.dark-theme` - темный градиент навигации

### Особенности
- Тема сохраняется между сессиями через `localStorage`
- Применяется синхронно при загрузке страницы (через inline скрипт в `<head>`)
- Изменяются только фон `body` и градиент навигационной панели

## 3. Пагинация товаров (ProductPagination)

### Расположение
- **Файл**: `static/js/product_pagination.js`
- **Использование**: Страница каталога (`templates/catalog/product_list.html`)

### Описание
Реализует клиентскую пагинацию для списка товаров с возможностью выбора количества элементов на странице.

### Основные компоненты

#### Конструктор
```javascript
constructor()
```
Инициализирует:
- `products` - массив объектов товаров
- `currentPage` - текущая страница (начинается с 1)
- `itemsPerPage` - количество элементов на странице (из `localStorage` или 3 по умолчанию)

#### Методы

**`init()`** - Инициализация:
1. Собирает все карточки товаров со страницы через `querySelectorAll('.product-card')`
2. Сохраняет их в массив `products`
3. Настраивает селектор количества элементов на странице
4. Рендерит первую страницу
5. Применяет 3D эффект к видимым карточкам

**`render()`** - Рендеринг текущей страницы:
1. Скрывает все товары (`display: none`)
2. Вычисляет диапазон товаров для текущей страницы
3. Показывает только товары текущей страницы (`display: block`)
4. Рендерит пагинацию
5. Применяет 3D эффект к видимым карточкам

**`renderPagination()`** - Создает элементы пагинации:
1. Вычисляет общее количество страниц
2. Создает кнопки:
   - "Первая" (если не на первой странице)
   - "Назад" (если не на первой странице)
   - Номера страниц (до 5 видимых, с многоточием при необходимости)
   - "Вперед" (если не на последней странице)
   - "Последняя" (если не на последней странице)
3. Добавляет обработчики кликов на кнопки

**`init3DEffects()`** - Применяет 3D эффект к видимым карточкам:
1. Определяет видимые карточки для текущей страницы
2. Для каждой карточки добавляет обработчики событий:
   - `mouseenter` - убирает transition для плавности
   - `mousemove` - вычисляет угол наклона на основе позиции мыши
   - `mouseleave` - возвращает карточку в исходное положение
3. Использует `dataset.effect3d` для предотвращения дублирования обработчиков

### Использование
Автоматически инициализируется при загрузке страницы:
```javascript
document.addEventListener('DOMContentLoaded', function() {
    new ProductPagination();
});
```

### Особенности
- Количество элементов на странице сохраняется в `localStorage`
- При изменении количества элементов возвращается на первую страницу
- 3D эффект применяется только к видимым карточкам для оптимизации
- Пагинация скрывается, если товаров меньше или равно `itemsPerPage`

## 4. 3D эффект карточек товаров

### Расположение
- **Файл**: `static/js/product_card_3d.js`
- **Использование**: Страница каталога (но фактически эффект применяется через `ProductPagination`)

### Описание
Создает эффект объема при наведении мыши на карточки товаров.

### Механизм работы

#### Обработчики событий

**`mouseenter`** - При входе мыши:
- Убирает CSS transition для мгновенной реакции

**`mousemove`** - При движении мыши:
1. Получает позицию мыши относительно карточки (`getBoundingClientRect()`)
2. Вычисляет центр карточки
3. Вычисляет углы поворота:
   - `rotateX` = (y - centerY) / 10
   - `rotateY` = (centerX - x) / 10
4. Применяет transform с perspective:
   ```javascript
   transform: perspective(1000px) rotateX(${rotateX}deg) rotateY(${rotateY}deg) translateY(-5px)
   ```
5. Увеличивает тень для эффекта глубины

**`mouseleave`** - При выходе мыши:
- Возвращает transition для плавного возврата
- Сбрасывает transform в исходное состояние
- Возвращает обычную тень

### Особенности
- Эффект применяется динамически через `ProductPagination.init3DEffects()`
- Использует CSS `perspective` для создания 3D эффекта
- Угол наклона зависит от позиции мыши относительно центра карточки

## 5. Таблица контактов (ContactsTable)

### Расположение
- **Файл**: `static/js/contacts_table.js`
- **Использование**: Страница демонстрации (`templates/home/demo.html`)

### Описание
Полнофункциональная таблица контактов с сортировкой, фильтрацией, пагинацией, добавлением новых записей и функцией премирования.

### Основные компоненты

#### Конструктор
```javascript
constructor(data)
```
- `data` - массив объектов контактов
- Инициализирует:
  - `originalData` - исходные данные
  - `filteredData` - отфильтрованные данные
  - `currentData` - данные для текущего отображения
  - `currentPage` - текущая страница
  - `itemsPerPage` - элементов на странице (3)
  - `sortColumn` - текущая колонка сортировки
  - `sortDirection` - направление сортировки ('asc'/'desc')
  - `selectedRows` - Set с ID выбранных строк

#### Методы

**`init()`** - Инициализация:
1. Рендерит таблицу
2. Настраивает обработчики событий
3. Рендерит пагинацию

**`setupEventListeners()`** - Настройка обработчиков:
- Кнопка добавления - показывает форму
- Кнопка отмены - скрывает форму и сбрасывает её
- Клики по заголовкам - сортировка
- Кнопка фильтрации - применяет фильтр
- Отправка формы - добавляет контакт
- Валидация URL и телефона при потере фокуса
- Кнопка премирования - показывает прелоадер и результат

**`renderTable()`** - Рендеринг таблицы:
1. Очищает тело таблицы
2. Вычисляет диапазон данных для текущей страницы
3. Для каждого контакта создает строку:
   - Ячейки с данными
   - Чекбокс для выбора
   - Обработчик клика по строке (показывает детали)
   - Обработчик изменения чекбокса (добавляет/удаляет из выбранных)
4. Обновляет индикаторы сортировки

**`sortTable(column)`** - Сортировка:
1. Определяет направление сортировки (переключает при повторном клике)
2. Сортирует `currentData` по указанной колонке
3. Обновляет таблицу и пагинацию

**`filterTable()`** - Фильтрация:
1. Получает текст из поля поиска
2. Фильтрует `filteredData` по всем полям
3. Обновляет `currentData`
4. Сбрасывает на первую страницу
5. Обновляет таблицу и пагинацию

**`renderPagination()`** - Пагинация:
- Создает кнопки "Назад", номера страниц, "Вперед"
- Отключает кнопки на границах
- Выделяет активную страницу

**`showRowDetails(contact)`** - Показывает детали контакта:
- Отображает все поля контакта в отдельном блоке
- Показывает большое фото

**`validateURL()`** - Валидация URL:
- Паттерн: `/^https?:\/\/.+\.(php|html)$/i`
- Должен начинаться с `http://` или `https://`
- Должен заканчиваться на `.php` или `.html`
- Показывает сообщение об ошибке/успехе

**`validatePhone()`** - Валидация телефона:
- Паттерн: `/^(\+375|8)\s?\(?\d{2,3}\)?\s?\d{2,3}[\s-]?\d{2}[\s-]?\d{2}$/`
- Может начинаться с `+375` или `8`
- Код оператора в скобках или без
- Остальное с дефисами и пробелами

**`checkFormValidity()`** - Проверка валидности формы:
- Проверяет заполненность всех полей
- Проверяет валидность URL и телефона
- Включает/отключает кнопку отправки

**`addContact()`** - Добавление контакта:
1. Создает новый объект контакта с временным ID
2. Добавляет в `originalData`, `filteredData`, `currentData`
3. Сбрасывает фильтр и сортировку
4. Переходит на последнюю страницу
5. Обновляет таблицу и пагинацию
6. Скрывает форму

**`premiateSelected()`** - Премирование выбранных:
1. Проверяет наличие выбранных сотрудников
2. Показывает прелоадер на 5 секунд
3. Извлекает фамилии выбранных сотрудников
4. Отображает сообщение о премировании
5. Сбрасывает выбор

**`escapeHtml(text)`** - Экранирование HTML:
- Предотвращает XSS атаки
- Использует создание временного элемента

### Использование
```javascript
const contactsTable = new ContactsTable(contactsData);
```

### Особенности
- Данные передаются из Django шаблона в JavaScript
- Валидация происходит в реальном времени
- Прелоадер показывается в нижнем левом углу экрана
- Выбранные строки отслеживаются через `Set`

## 6. Генератор элементов Select

### Расположение
- **Файл**: `static/js/select_generator.js`
- **Использование**: Страница демонстрации (`templates/home/demo.html`)

### Описание
Позволяет динамически создавать элементы `<select>` с настраиваемыми атрибутами и опциями. Все созданные элементы сохраняются в `localStorage`.

### Основные компоненты

#### Конструктор
```javascript
constructor()
```
- Инициализирует массив `selects` для хранения конфигураций
- Загружает сохраненные элементы из `localStorage`

#### Методы

**`init()`** - Инициализация:
1. Загружает сохраненные элементы из `localStorage`
2. Настраивает чекбокс включения генератора
3. Настраивает кнопку добавления нового select
4. Восстанавливает состояние чекбокса из `localStorage`

**`addSelect()`** - Добавление нового select:
1. Создает уникальный ID на основе времени
2. Создает объект конфигурации с параметрами по умолчанию:
   - `name` - имя элемента
   - `multiple` - множественный выбор (false)
   - `size` - размер списка (1)
   - `required` - обязательное поле (false)
   - `disabled` - отключенное поле (false)
   - `options` - массив опций (пустой)
3. Добавляет в массив `selects`
4. Рендерит select
5. Сохраняет в `localStorage`

**`renderSelect(selectData)`** - Рендеринг select:
1. Создает обертку `select-wrapper` с уникальным ID
2. Добавляет блок управления с кнопкой удаления
3. Добавляет блок конфигурации с полями:
   - Текстовое поле для `name`
   - Чекбоксы для `multiple`, `required`, `disabled`
   - Числовое поле для `size`
   - Текстовое поле для опций (через запятую)
4. Добавляет блок предпросмотра с реальным `<select>` элементом
5. Настраивает обработчики событий

**`setupEventListeners(wrapper, selectData)`** - Обработчики событий:
- Для каждого поля конфигурации добавляет обработчик `input`/`change`
- При изменении обновляет `selectData` и предпросмотр
- Сохраняет изменения в `localStorage`
- Кнопка удаления вызывает `removeSelect()`

**`updatePreview(selectData)`** - Обновление предпросмотра:
1. Очищает предыдущие опции
2. Устанавливает атрибуты:
   - `name` - если указано
   - `multiple` - если включено
   - `size` - значение из поля
   - `required` - если включено
   - `disabled` - если включено
3. Добавляет опции из массива `options`
4. Если опций нет, добавляет пустую опцию "Выберите..."

**`removeSelect(id)`** - Удаление select:
1. Удаляет из массива `selects`
2. Удаляет DOM элемент
3. Сохраняет изменения в `localStorage`
4. Обновляет номера элементов

**`updateNumbers()`** - Обновление номеров:
- Пересчитывает номера элементов после удаления

**`saveToStorage()`** - Сохранение в localStorage:

## 8. Управление сотрудниками (Классы и наследование)

### Расположение
- **Файл**: `static/js/employees_classes.js`
- **Использование**: Страница демонстрации (`templates/home/demo.html`)

### Описание
Демонстрирует два способа реализации наследования в JavaScript: прототипное наследование и ES6 классы с `extends`. Реализует анализ вероятности брака между сотрудниками.

### Структура классов

#### Вариант 1: Прототипное наследование

**Базовый класс `Employee`:**
```javascript
function Employee(name, gender, maritalStatus)
```
- Конструктор функции
- Свойства: `name`, `gender`, `maritalStatus`
- Методы в прототипе:
  - Геттеры: `getName()`, `getGender()`, `getMaritalStatus()`
  - Сеттеры: `setName()`, `setGender()`, `setMaritalStatus()`
  - `addFromForm(formData)` - добавление данных из формы
  - `display()` - вывод на страницу
  - `checkMarriageProbability(employees)` - проверка вероятности брака

**Класс наследник `ExtendedEmployee`:**
```javascript
function ExtendedEmployee(name, gender, maritalStatus, department)
```
- Вызывает конструктор родителя через `Employee.call(this, ...)`
- Добавляет свойство `department`
- Наследует прототип через `Object.create(Employee.prototype)`
- Переопределяет `addFromForm()` и `display()`
- Добавляет геттер/сеттер для `department`

#### Вариант 2: ES6 классы

**Базовый класс `EmployeeClass`:**
```javascript
class EmployeeClass {
    constructor(name, gender, maritalStatus)
}
```
- Использует приватные свойства с префиксом `_`
- Те же методы, что и в прототипном варианте

**Класс наследник `ExtendedEmployeeClass`:**
```javascript
class ExtendedEmployeeClass extends EmployeeClass {
    constructor(name, gender, maritalStatus, department) {
        super(name, gender, maritalStatus);
    }
}
```
- Использует `extends` для наследования
- Вызывает `super()` в конструкторе
- Переопределяет методы через `super.methodName()`

### Метод `checkMarriageProbability(employees)`

Анализирует массив сотрудников и определяет вероятность брака:
1. Фильтрует сотрудников, состоящих в браке (статус "женат" или "замужем")
2. Проверяет, что таких сотрудников минимум 2
3. Разделяет на мужчин и женщин
4. Если есть и женатые мужчины, и замужние женщины:
   - Вероятность ВЫСОКАЯ
5. Если все одного пола:
   - Вероятность НИЗКАЯ

### Функции управления

**`initPrototypeTab()`** - Инициализация вкладки прототипного наследования:
- Отображает начальный массив сотрудников
- Обработчик добавления нового сотрудника
- Обработчик проверки вероятности брака
- Функция `renderProtoList()` для отображения списка

**`initClassTab()`** - Инициализация вкладки классов:
- Аналогично прототипной вкладке, но использует ES6 классы

**`initTabs()`** - Переключение вкладок:
- Обработчики кликов на кнопки вкладок
- Показывает/скрывает соответствующий контент

### Использование
Автоматически инициализируется при загрузке страницы:
```javascript
document.addEventListener('DOMContentLoaded', function() {
    initTabs();
    initPrototypeTab();
    initClassTab();
});
```

### Особенности
- Демонстрирует два подхода к наследованию
- Начальный массив из 5 сотрудников предзаполнен
- Можно добавлять новых сотрудников через форму
- Алгоритм анализа брака работает одинаково для обоих вариантов
- Использует вкладки для переключения между вариантами

## 9. Демонстрация Web API

### Расположение
- **Файл**: `static/js/web_api_demo.js`
- **Использование**: Страница демонстрации (`templates/home/demo.html`)

### Описание
Демонстрирует использование двух Web API: Geolocation API и Battery Status API.

### Компоненты

#### Функция `initAPIDemoComponent(container)`

Создает HTML структуру и инициализирует компоненты:
- Секция Geolocation API
- Секция Battery Status API

### Geolocation API

#### Функция `getMyLocation()`
Получает текущее местоположение пользователя:
1. Проверяет поддержку `navigator.geolocation`
2. Вызывает `getCurrentPosition()`:
   - Успех: получает координаты (широта, долгота, точность)
   - Вызывает `reverseGeocode()` для получения адреса
   - Ошибка: показывает сообщение об ошибке

#### Функция `reverseGeocode(lat, lon, accuracy)`
Обратный геокодинг через OpenStreetMap Nominatim API:
1. Формирует URL запроса
2. Отправляет GET запрос с заголовком User-Agent
3. Парсит JSON ответ
4. Извлекает `display_name` (адрес)
5. Вызывает `showLocationOnMap()` для отображения

#### Функция `searchLocationByAPI()`
Поиск местоположения по названию:
1. Получает поисковый запрос из поля ввода
2. Формирует URL для Nominatim API
3. Отправляет запрос с кодированием через `encodeURIComponent()`
4. Обрабатывает ответ:
   - Если найдено: извлекает координаты и название
   - Если не найдено: показывает ошибку
5. Вызывает `showLocationOnMap()` для отображения

#### Функция `showLocationOnMap(latitude, longitude, locationName, accuracy)`
Отображает результаты геолокации:
1. Форматирует координаты с 6 знаками после запятой
2. Показывает точность (если доступна)
3. Создает ссылки на:
   - OpenStreetMap
   - Google Maps
4. Отображает информацию в блоке результатов

### Battery Status API

#### Функция `getBatteryInfo()`
Получает информацию о батарее устройства:
1. Проверяет поддержку `navigator.getBattery`
2. Если не поддерживается: вызывает `showBatteryDemo()`
3. Если поддерживается:
   - Вызывает `navigator.getBattery()` (возвращает Promise)
   - Извлекает данные:
     - `level` - уровень заряда (0-1, преобразуется в проценты)
     - `charging` - идет ли зарядка
     - `chargingTime` - время до полной зарядки (в секундах)
     - `dischargingTime` - время до разрядки (в секундах)
   - Добавляет слушатели событий:
     - `levelchange` - изменение уровня
     - `chargingchange` - изменение статуса зарядки
   - Вызывает `displayBatteryInfo()` для отображения

#### Функция `showBatteryDemo()`
Демонстрационный режим для браузеров без поддержки:
1. Создает симулированные данные (75% заряда)
2. Добавляет кнопки управления:
   - Уменьшить заряд
   - Увеличить заряд
   - Переключить зарядку
3. Обновляет отображение при изменении

#### Функция `displayBatteryInfo(level, charging, chargingTime, dischargingTime, isDemo)`
Отображает информацию о батарее:
1. Определяет цвет индикатора:
   - Красный: < 20%
   - Оранжевый: 20-50%
   - Зеленый: > 50%
2. Создает визуальный индикатор прогресса
3. Отображает все данные
4. Если демо-режим: показывает предупреждение и кнопки управления

### Использование
Автоматически инициализируется при загрузке страницы:
```javascript
document.addEventListener('DOMContentLoaded', function() {
    const container = document.getElementById('api-demo-container');
    if (container) {
        initAPIDemoComponent(container);
    }
});
```

### Особенности
- Использует бесплатный API OpenStreetMap Nominatim
- Обрабатывает ошибки сети и API
- Демонстрационный режим для Battery API в браузерах без поддержки
- Автоматическое обновление данных батареи при изменении
- Ссылки на карты для визуализации местоположения

## 10. Визуализация графика функции

### Расположение
- **Файл**: `static/js/chart_visualizer.js`
- **Использование**: Страница демонстрации (`templates/home/demo.html`)
- **Зависимости**: Chart.js библиотека

### Описание
Визуализирует функцию `ln(1+x)` через сравнение ряда Тейлора с точным значением `Math.log(1+x)`. Позволяет настраивать параметры, строить график и сохранять данные.

### Компоненты

#### Функция `initChartVisualizerComponent(container)`

Создает HTML структуру с:
- Полями управления параметрами
- Canvas для графика
- Кнопками действий
- Таблицей данных

#### Параметры по умолчанию
```javascript
{
    xMin: -0.9,      // Начало диапазона X
    xMax: 0.9,       // Конец диапазона X
    xStep: 0.1,      // Шаг по X
    termsCount: 10   // Количество членов ряда Тейлора
}
```

#### Функции вычисления

**`calculateSeries(x, n)`** - Вычисление ряда Тейлора:
```javascript
ln(1+x) = x - x²/2 + x³/3 - x⁴/4 + ...
```
- Формула: `∑(-1)^(i-1) * x^i / i` для i от 1 до n
- Использует `Math.pow()` для возведения в степень

**`calculateMath(x)`** - Точное значение:
- Использует `Math.log(1 + x)`

#### Функция `buildChart()`

Основная функция построения графика:
1. Получает параметры из полей ввода
2. Валидирует параметры:
   - `xMin < xMax`
   - Значения в диапазоне (-1, 1) для сходимости ряда
3. Генерирует массив значений:
   - Для каждого x от `xMin` до `xMax` с шагом `xStep`:
     - Вычисляет значение ряда Тейлора
     - Вычисляет точное значение
     - Вычисляет погрешность (eps)
     - Сохраняет в `tableData`
4. Уничтожает предыдущий график (если есть)
5. Создает новый график Chart.js:
   - Тип: `line`
   - Два датасета:
     - Точное значение (красная линия, order: 2)
     - Ряд Тейлора (синяя линия, order: 1)
   - Настройки осей и легенды
6. Обновляет таблицу данных

#### Функция `updateTable()`

Обновляет таблицу данных:
- Форматирует числа:
  - x: 2 знака после запятой
  - F(x): 6 знаков после запятой
  - eps: экспоненциальная форма (2 знака)

#### Функция `saveAsImage()`

Сохранение графика как изображение:
1. Проверяет наличие графика
2. Использует `chart.toBase64Image()` для получения base64
3. Создает ссылку `<a>` с атрибутом `download`
4. Программно кликает по ссылке
5. Файл сохраняется как `ln_function_chart.png`

#### Функция `saveDataToFile()`

Сохранение данных в текстовый файл:
1. Форматирует данные в текстовый формат:
   - Заголовок и параметры
   - Таблица с разделителями
2. Создает Blob с типом `text/plain`
3. Создает URL через `URL.createObjectURL()`
4. Создает ссылку и программно кликает
5. Освобождает URL через `URL.revokeObjectURL()`
6. Файл сохраняется как `ln_function_data.txt`

### Использование
Автоматически инициализируется при загрузке страницы:
```javascript
document.addEventListener('DOMContentLoaded', function() {
    const container = document.getElementById('chart-visualizer-container');
    if (container) {
        initChartVisualizerComponent(container);
    }
});
```

### Особенности
- Использует библиотеку Chart.js для построения графиков
- График строится автоматически при загрузке с параметрами по умолчанию
- Таблица данных скрыта по умолчанию, можно показать/скрыть кнопкой
- Валидация параметров предотвращает ошибки вычислений
- Два графика наложены друг на друга для сравнения
- Порядок отрисовки (order) определяет, какой график поверх

## 11. Анимация конвейера при скроллинге

### Расположение
- **Файл**: `static/js/conveyor_animation.js`
- **Использование**: Главная страница (`templates/home/index.html`)

### Описание
Создает анимацию движения товаров по конвейеру при скроллинге страницы. Каждый товар может иметь индивидуальные настройки движения.

### Основные компоненты

#### Конструктор
```javascript
constructor()
```
Инициализирует:
- `lastScrollTop` - последняя позиция скролла
- `scrollDirection` - направление скролла (1 или -1)
- `products` - массив объектов товаров

#### Методы

**`init()`** - Инициализация:
1. Загружает товары через `loadProducts()`
2. Добавляет обработчик события `scroll`
3. Вызывает `handleScroll()` для начальной позиции

**`loadProducts()`** - Загрузка товаров:
1. Определяет конфигурацию каждого товара в массиве `productConfigs`
2. Для каждого товара можно задать:
   - `imageSrc` - путь к изображению
   - `initialLeft` - начальная позиция по горизонтали (px)
   - `initialTop` - начальная позиция по вертикали (px)
   - `speedMultiplier` - множитель скорости (0.4 = медленнее, 1.0 = нормально)
   - `direction` - направление горизонтального движения (1 = вправо, -1 = влево)
   - `verticalSpeed` - скорость вертикального движения (0 = не движется)
   - `verticalDirection` - направление вертикального движения (1 = вниз, -1 = вверх)
3. Создает DOM элементы для каждого товара
4. Сохраняет объекты товаров в массив `products`

**`handleScroll()`** - Обработка скролла:
1. Получает элемент секции конвейера
2. Вычисляет позицию секции через `getBoundingClientRect()`
3. Определяет направление скролла:
   - Вниз: `scrollDirection = 1`
   - Вверх: `scrollDirection = -1`
4. Проверяет видимость секции:
   - `isVisible`: секция частично видна на экране
   - `isInWorkingZone`: секция в пределах ±200px от экрана
5. Если секция видна и в рабочей зоне:
   - Вычисляет скорость на основе направления
   - Вызывает `animateProducts(speed)`
6. Если секция не видна:
   - Останавливает анимацию (`speed = 0`)

**`animateProducts(speed)`** - Анимация товаров:
1. Получает размеры конвейера
2. Для каждого товара:
   - Вычисляет индивидуальную скорость:
     ```javascript
     individualSpeed = speed * speedMultiplier * direction
     ```
   - Обновляет горизонтальную позицию
   - Если `verticalSpeed !== 0`:
     - Вычисляет вертикальное движение
     - Обновляет вертикальную позицию
     - Ограничивает вертикальное движение границами конвейера
   - Если товар ушел за правый край:
     - Перемещает в начало (`position = -100`)
   - Если товар ушел за левый край:
     - Перемещает в конец (`position = conveyorWidth`)
   - Применяет новые позиции к DOM элементам

### Использование
Автоматически инициализируется при загрузке страницы:
```javascript
document.addEventListener('DOMContentLoaded', function() {
    new ConveyorAnimation();
});
```

### Особенности
- Анимация работает только когда секция конвейера видна на экране
- Каждый товар может двигаться с индивидуальной скоростью и направлением
- Поддержка вертикального движения для создания сложных траекторий
- Товары циклически перемещаются по конвейеру
- Скорость зависит только от направления скролла (не от скорости скролла)
- Рабочая зона ограничена ±200px от границ экрана для оптимизации

### Пример конфигурации товара
```javascript
{
    imageSrc: '/media/pipe/bear1.png',
    initialLeft: 40,           // Начало слева
    initialTop: -20,           // Выше центра на 20px
    speedMultiplier: 0.4,      // Медленнее обычного
    direction: 1,              // Вправо при скролле вниз
    verticalSpeed: 0.6,        // Движется вниз
    verticalDirection: 1       // Вниз при скролле вниз
}
```

- **ContactsTable**: валидация URL и телефона через регулярные выражения
- **AgeChecker**: проверка валидности даты и что она не в будущем
- **Chart Visualizer**: проверка диапазонов и параметров

### Обработка ошибок
- Проверка наличия элементов перед использованием
- Try-catch блоки для асинхронных операций
- Сообщения об ошибках для пользователя

### Оптимизация производительности
- **Product Pagination**: 3D эффект применяется только к видимым карточкам
- **Conveyor Animation**: анимация работает только в рабочей зоне
- Использование `dataset` атрибутов для предотвращения дублирования обработчиков
